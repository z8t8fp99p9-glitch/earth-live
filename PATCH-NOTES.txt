EARTH // LIVE — Global Display Mode v1.5.4

Consolidated candidate containing the full-display viewport work and persistent display-mode selection.
- Default mode is Full Screen (full display viewport).
- With Cuts mode uses browser-reported safe-area insets.
- User choice is stored in localStorage under earthLiveDisplayMode and restored on subsequent launches.
- Orientation/viewport changes do not change the saved mode; they only update responsive profile detection.
- Portrait target: 80% of full viewport width, centered.
- Landscape target: 70% of full viewport height, 3% top target.
- The mode switch does not intentionally reset camera position or gesture state.
- No data-store.js included or modified.

Validation: JavaScript syntax and ZIP integrity checked. Not visually tested on an iPhone.
Note: this package retains the supplied v1.5.2 app structure; its primary dock remains an empty placeholder and More Options is a temporary top-right entry point, not the original five-button deck integration.
