EARTH // LIVE — Adaptive Display + Gesture Recovery v1.4.8

Purpose
- Preserve the adaptive display composition from v1.4.7.
- Restore the earlier 10-metre minimum camera distance requested by the user.
- Keep the earlier per-orientation zoom tuning: portrait 8.63, compact 6.5, landscape/ultrawide 5.
- Keep Cesium native camera gesture controls enabled; this patch does not introduce custom gesture recognizers.
- Resize handler remains limited to resizing the renderer and updating profile sensitivity; it does not reframe/reset the camera.
- Deck CSS is unchanged. Database and unrelated features are untouched.

Checks
- JavaScript syntax check and ZIP integrity check performed.
- Not tested in a live browser or on the user's iPhone.
- One-gesture-at-a-time exclusion of pinch-vs-rotation is not yet custom-enforced; native Cesium gestures are preserved in this pass to avoid damaging the previously tuned interaction feel. Test this build before adding a dedicated gesture lock.
