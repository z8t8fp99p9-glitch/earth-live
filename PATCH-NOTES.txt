EARTH // LIVE — Global Display Modes v1.5.5

Display Personalisation options:
- Full Screen (default on first launch)
- Cutouts at Top
- Cutouts at Bottom
- Cutouts at Top & Bottom

The selected mode is stored in localStorage as earthLiveDisplayMode and restored on later launches. Viewport/orientation changes adapt layout but do not overwrite the saved selection.

Adaptive globe targets:
- Portrait/compact: 80% of the selected display area's width, centered.
- Landscape/ultrawide: 60% of the selected display area's height, with a 2% top-position target.

The four modes apply browser-reported safe-area insets at the selected edges. Full Screen uses the complete viewport. Existing gesture implementation and imagery setup are retained. data-store.js is not included or modified.

Validation: JavaScript syntax and ZIP integrity checks performed. Not visually verified on a physical iPhone. More Options remains the temporary top-right entry point; integration into the original five-button deck is separate work.
