EARTH // LIVE v1.5.6 — Global Display Variable

Fixes found in v1.5.5:
- All display modes now use the selected #globe box as the authoritative viewport; removed the 100vw minimum-width constraint that overrode cutout layouts.
- Explicitly changing a display mode waits for CSS layout, resizes Cesium, and recalculates adaptive camera framing for the selected viewport.
- Orientation profile changes recalculate framing before user interaction; explicit mode changes recalculate even after interaction.
- Four persistent choices retained: Full Screen (default), Cutouts at Top, Cutouts at Bottom, Cutouts at Top & Bottom.
- Portrait target 80% width centred; landscape target 60% height with 2% top target.
- No changes to imagery provider, gesture handlers, dock CSS, or data-store.js.

Candidate only: syntax and archive integrity checked; physical-device visual behavior still requires user testing.
