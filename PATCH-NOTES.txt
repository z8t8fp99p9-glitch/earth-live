EARTH // LIVE v1.5.24 — width-driven adaptive orb sizing

Upload these files to the repository root on main, replacing matching files:
- index.html
- style.css

Design rules:
- Orb diameter is controlled by CSS width (clamp), not viewport height.
- Height follows width with aspect-ratio: 1 / 1, preserving circular orbs.
- The dock stays centered, bottom-anchored, and capped at 390 CSS px in both orientations.
- Six equal grid columns keep the orbs evenly distributed.
- Labels can wrap within each column.
- A short-landscape fallback reduces orb diameter only for very short screens.
- No JavaScript resize loop or camera logic was added or modified.
- Existing image assets, app.js, app-version.js, data-store.js, and database files are untouched.

Validation:
- ZIP structure checked.
- This patch has not been verified live on an iPhone; check portrait and landscape after deployment.
