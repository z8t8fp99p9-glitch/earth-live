EARTH // LIVE — v1.5.7 Adaptive Display Area

Purpose
- Correct orientation-dependent globe sizing using one shared global display-area object.
- Keep the user's selected display mode persistent: Full Screen, Cutouts at Top, Cutouts at Bottom, Cutouts at Top & Bottom.
- Re-measure the selected display rectangle after mode changes, orientation changes, viewport resizes, and pageshow.
- Portrait globe target: 80% of the selected area's width.
- Landscape globe target: 60% of the selected area's height, with a 2% top-edge target.
- Orientation changes trigger the matching layout composition even if the globe was previously interacted with. Same-orientation resizes do not reframe.

Protected
- No changes to data-store.js.
- No changes to the globe touch-gesture handler implementation.
- Existing imagery and other layers are preserved.

Validation
- JavaScript syntax and ZIP integrity checked.
- Not tested on a physical iPhone; device verification is still required.
