EARTH // LIVE v1.5.9 — Global Display Coordinate System

Whole-layout correction based on the current v1.5.8 source.

- The selected display mode now bounds #app, the shared coordinate root for the globe and interface overlays.
- Globe, Personalisation button/panel, and attribution use the same selected display rectangle; safe-area insets are not applied independently to the globe only.
- One orientation detector returns only the supported profiles: portrait or landscape.
- Current dimensions are remeasured after rotation, resize, page restoration, and mode selection.
- Portrait globe target remains 80% of selected area width. Landscape target remains 60% of selected area height, with a 2% top target on initial framing.
- Camera range recalculates on layout transitions; after initial launch, the current camera location/orientation is preserved rather than snapping back to the startup coordinates.
- Cache-busting URLs, service-worker cache, and app version are aligned to v1.5.9.
- Existing gesture handlers are unchanged. data-store.js is not included or modified.

Validation: JavaScript syntax and ZIP integrity are checked. Physical iPhone/browser rendering still requires user verification.
