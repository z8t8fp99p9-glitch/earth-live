EARTH // LIVE v1.5.10 — Map Orientation Synchronization

Purpose: fix globe camera framing when iOS rotates between portrait and landscape.

Changes:
- Wait two animation frames before applying orientation-dependent camera framing.
- Synchronize the current selected display rectangle, Cesium canvas size, and perspective-frustum aspect ratio.
- Calculate horizontal/vertical field of view from the current aspect ratio instead of relying on a potentially stale fovy value from the previous orientation.
- Recompute globe camera range on genuine orientation transitions while preserving the current geographic camera position and orientation.
- Update asset query strings, service-worker cache, and app version together.

Protected: data-store.js is not included; gesture-handler code is unchanged.

Validation: JavaScript syntax and ZIP integrity are checked. Real-device iPhone validation is still required.


v1.5.11 — Orientation-safe-area fix

- Initial startup framing remains unchanged.
- Gesture handlers and data-store.js remain untouched.

Validation: app.js syntax and ZIP integrity checked; real-device verification remains necessary.
