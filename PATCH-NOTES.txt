EARTH // LIVE — Adaptive Display v1.4.4

Changed files (flat ZIP, repository root):
- app.js: replace fixed camera-space lift with viewport/frustum-derived initial globe framing.
- index.html: update cache-busting version query strings.
- app-version.js: version stamp.
- service-worker.js: cache version.

Layout targets:
- Portrait: globe apparent diameter targets 80% of viewport width.
- Landscape/ultrawide: globe apparent diameter targets 75% of viewport height, with its top edge targeted near 2.5% below the viewport top.
- Actual size is calculated from Cesium's frustum and current viewport; no CSS canvas translation is used.
- Initial layout can adapt on resize/orientation changes until the user begins interacting. After user interaction, their camera is not reset.

Preserved: full-screen globe canvas and native Cesium gestures, imagery setup, database, and deck CSS. No orb assets or Stacks UI added.

Validation: JavaScript syntax and ZIP integrity checks only. Not tested in a live browser or on iPhone. Please test portrait and landscape after upload.
