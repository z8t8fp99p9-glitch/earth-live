EARTH // LIVE — Earthquake Dataset v1.0
MANUAL INTEGRATION ONLY — DO NOT REPLACE THE APP

1. Keep a copy of your current working files.
2. Upload `earthquake-dataset.js` beside `index.html`.
3. In `index.html`, add this script tag AFTER `data-store.js` and BEFORE `app.js`:
   <script src="./earthquake-dataset.js"></script>
4. Do not replace `app.js`, `data-store.js`, `app-version.js`, or `index.html` wholesale.
5. This package adds no visible controls or map markers. It only provides a collector module.
6. Verify after deployment (using a browser console/test harness):
   typeof window.EarthLiveEarthquakes
   window.EarthLiveEarthquakes.health()
7. To request a collection refresh from a deliberate test action:
   window.EarthLiveEarthquakes.refresh()
8. To start the active-app collector:
   window.EarthLiveEarthquakes.start()
   To stop:
   window.EarthLiveEarthquakes.stop()
9. The module starts automatically only if `window.EarthLiveCollections` is already available when it loads; otherwise call `start()` after the store is ready.
10. This package has not been runtime-tested inside the iPhone PWA. Verify source access and local storage before treating it as installed.
