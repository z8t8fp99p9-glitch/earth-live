EARTH // LIVE — Moon Dataset v1.0
MANUAL INTEGRATION ONLY — DO NOT REPLACE THE APP

1. Back up your current working app files.
2. Upload `moon-dataset.js` beside `index.html`.
3. Add this script tag in `index.html` AFTER `data-store.js` and BEFORE `app.js`:
   <script src="./moon-dataset.js"></script>
4. Do not replace `app.js`, `data-store.js`, `app-version.js`, textures, or other existing files wholesale.
5. This package adds no UI, marker, camera-follow behavior, timer, or automatic database writes.
6. After integration, verify:
   typeof window.EarthLiveMoon
   window.EarthLiveMoon.calculate(new Date())
   window.EarthLiveMoon.health()
7. For a selected simulation time:
   window.EarthLiveMoon.calculate(new Date("2026-10-14T12:00:00Z"))
8. To explicitly save a compact local snapshot:
   await window.EarthLiveMoon.saveSnapshot(new Date())
9. Runtime-test representative dates against a trusted ephemeris before relying on positional accuracy.
10. This module is not runtime-tested in the installed iPhone PWA.
