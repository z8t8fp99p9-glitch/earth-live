EARTH // LIVE — Live Location Dataset v1.0

1. Upload `location-dataset.js` to the repository root.
2. In the existing `index.html`, add this script after `data-store.js` and before `app.js`:
   <script src="./location-dataset.js"></script>
3. Do not replace `index.html`, `app.js`, `style.css`, `data-store.js`, or the service worker.
4. Open the app on HTTPS and tap the existing Location button. Approve location permission if desired.
5. Verify local record count via the existing EarthLiveCollections.stats() API in a suitable developer console; this package does not display coordinates or add UI.

No assistant-side GitHub changes were made.
